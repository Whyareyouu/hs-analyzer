# CLI И Output

## Основные правила

- Основной бинарь: `cmd/hsanalyzer`.
- Основная команда анализа: `go run ./cmd/hsanalyzer analyze ...`
- Автосохранение timeline JSON должно происходить всегда.

## Каталог output

- Все `timeline_*.json` должны сохраняться только в корневой каталог `output` проекта.
- Нельзя вычислять `output` от случайной текущей директории процесса.
- Корень проекта определяется через поиск `go.mod`.

## Форматы вывода

- `--format text` отвечает за текстовый вывод.
- `--format json` отвечает за JSON-вывод.
- Независимо от `--format`, timeline JSON должен быть сохранен автоматически.

## Требование к timeline JSON

- Формат: массив ходов.
- Каждый ход содержит хронологию событий.
- Для карт и сущностей вывод должен быть максимально человекочитаемым:
  - `id`
  - `name`
  - `info`
  - если нужно, `entity_id`, `card_id`, `owner`, `zone`, `position`
