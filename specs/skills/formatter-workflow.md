# Skill: Formatter Workflow

## Цель

Formatter должен объяснять игру человеку, а не просто сериализовать технические идентификаторы.

## Правила для TextFormatter

- По возможности использовать имя карты, а не только `card id`.
- Эффекты должны быть человекочитаемыми.
- Если есть известный keyword, показывать локализованное описание.

## Правила для JSONFormatter

- JSON должен быть удобен для чтения человеком и для последующей автоматической обработки.
- Для событий с картами всегда пытаться добавлять:
  - `name`
  - `info`
- Для событий с сущностями всегда пытаться добавлять:
  - `entity_id`
  - `card_id`
  - `name`
  - `info`

## Источники обогащения

Порядок предпочтения:

1. данные прямо в event
2. данные из `state.State`
3. lookup в `data/cards.json` через `carddb`

## Что считать “недостаточным выводом”

Если в output остается только:
- `entity_id`
- `card_id`
- `type`

и человек не может понять, что произошло, значит formatter нужно обогатить.
