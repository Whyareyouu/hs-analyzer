# Skill: Repo Workflow

## Как начинать задачу

1. Сначала понять, в каком слое лежит изменение:
   - parser
   - analyzer/pipeline
   - formatter
   - CLI
2. Прочитать связанные файлы, а не гадать по названию.
3. Проверить существующие тесты рядом с нужным модулем.

## Как вносить изменения

1. Делать точечные правки.
2. Не ломать существующие интерфейсы без необходимости.
3. После изменений прогонять `gofmt`.
4. Затем прогонять релевантные `go test`.

## Как коммитить

- Commit message всегда на русском языке.
- Сообщение должно описывать результат, а не намерение.

Примеры:
- `Добавлена полная информация о картах в timeline JSON`
- `Исправлено сохранение output в корневой каталог проекта`

## Как общаться в задаче

- Писать коротко и по делу.
- Не обещать изменения, если они еще не сделаны.
- Если найдено расхождение с текущим поведением проекта, сначала проверить код и тесты.
