# Skill: Review Checklist

Перед завершением задачи агент должен проверить:

1. Используются ли реальные данные из `logs/`, если менялся parser.
2. Появились ли/обновились ли тесты для нового поведения.
3. Прогнан ли `gofmt`.
4. Прогнаны ли релевантные `go test`.
5. Не появились ли случайные артефакты:
   - `.tmp`
   - новые `timeline_*.json`
   - мусор в `cmd/hsanalyzer/output`
6. Сохраняется ли `timeline_*.json` в корневой `output`.
7. Не осталось ли технического JSON, который непонятен человеку.

Если делается commit:

8. Commit message на русском.
9. В коммит не должны попадать случайные runtime-артефакты.
