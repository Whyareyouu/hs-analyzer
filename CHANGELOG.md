# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## 0.0.2

- Добавлена команда `monitor` для live-мониторинга логов Hearthstone с периодическим статусом, корректной остановкой и восстановлением runtime state через `--state-file`.
- Реализованы discovery активных логов, live reader для растущих файлов и сегментация потока событий на отдельные игровые сессии через `SessionDetector`.
- Добавлен post-game pipeline для финализации live-сессий, повторных попыток сохранения и опционального flush незавершённой партии через `--persist-incomplete-flush`.
- Analyzer и JSON formatter теперь работают с несколькими матчами за один прогон: верхнеуровневый JSON-документ содержит `match_count` и массив `matches`.
- Автосохранение timeline переведено на именование `timeline_<timestamp>_{mode}.json`, а `replay`-режим дополнен полным документом состояния для восстановления матча.
- Обновлены конфигурация, документация и тестовое покрытие для live-monitoring, multi-match JSON и дальнейшего roadmap по хранению матчей.

## 0.0.1

- Инициализирован CLI-инструмент `hsanalyzer` на Go с командами `analyze` и `update-cards`.
- Реализованы доменные модели игры, событий, игроков, карт, зон и состояния партии.
- Добавлены парсеры `Power.log`, `Decks.log`, `LoadingScreen.log` / `LoadingScreen_old.log` и `Zone.log`.
- Реализован `Analyzer` и `Pipeline` для чтения логов, объединения событий, сортировки и применения их к состоянию игры.
- Добавлена загрузка базы карт из JSON и использование карточных данных в анализе и форматировании.
- Реализованы текстовый и JSON-форматтеры с человекочитаемым выводом событий, включая `Discover` и `effect_triggered`.
- Добавлена конфигурация через YAML, пример `configs/config.yaml` и structured logging через `zap`.
- Подготовлены unit- и integration-тесты, включая компактные fixtures в `tests/testdata`.
- Обновлена документация проекта: `README.md`, тестовые данные, примеры конфигурации и текущие ограничения.
