# 🧠 Hearthstone Post-Match Analyzer — AI Agents Specification (MVP)

## 📌 Общая цель
Разработать систему на Go, которая:
1. Читает логи Hearthstone
2. Преобразует их в события
3. Восстанавливает состояние матча
4. Генерирует хронологию игры (timeline)
5. Экспортирует результат в JSON и человекочитаемый формат

---

## ⚙️ Общие правила для всех агентов

Ты — senior Go разработчик.

### Обязательные принципы:
- Пиши production-ready код
- Не усложняй без необходимости
- Соблюдай разделение ответственности (SRP)
- Система должна быть расширяемой
- Логи могут быть неполными или поврежденными
- НИКОГДА не падай из-за неизвестных данных
- Любая неопределенность → `Unknown`

---

## 📦 Архитектурный pipeline
Logs → Reader → Parser → Classifier → State Engine → Timeline → Export

⚠️ Критические правила (ВАЖНО)
1. Строгое разделение ответственности
Агент	НЕЛЬЗЯ делать
Parser	понимать механику игры
Classifier	хранить состояние
State	парсить строки
Export	менять данные
2. Работа с неизвестными данными

Если что-то неизвестно:

НЕ угадывать
сохранять Raw
помечать как Unknown
3. Архитектурная устойчивость

Система должна:

переживать кривые логи
не терять события
позволять добавлять новые режимы
📊 Минимальный MVP (Definition of Done)

Система считается готовой, если:

✅ Читает лог матча
✅ Определяет начало и конец
✅ Разбивает на ходы
✅ Показывает сыгранные карты
✅ Учитывает добор
✅ Учитывает discover
✅ Генерирует JSON
✅ Генерирует читаемый отчет
✅ Не падает на неизвестных данных
