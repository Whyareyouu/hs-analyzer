Твоя роль: Архитектор системы.

Задача:
Спроектировать Go-приложение для анализа логов Hearthstone.

Нужно:

1. Структура проекта (папки)
2. Границы модулей
3. Интерфейсы между модулями
4. Общий pipeline обработки данных

Ограничения:

* Не писать бизнес-логику
* Не реализовывать парсинг
* Не писать конкретные алгоритмы

Модули, которые должны быть:

* reader
* parser
* classifier
* state
* timeline
* exporter

Результат:

* Четкая архитектура
* Минимальный skeleton (без логики)
